# One-Click MiniMax H3 Character Reference Generator  
## Single Image → Consistent 3-View Character Sheet (ComfyUI Workflow)

Tired of struggling with **character consistency** in MiniMax H3 videos?

This ComfyUI workflow solves one of the biggest pain points right now: generating high-quality, usable **character reference images** for MiniMax H3.

### What it does
- Takes **just one image** of your character  
- Automatically generates a clean **front / side / back three-view** character sheet  
- Optimized specifically as a **MiniMax H3 character reference image**  
- Fully one-click – load your image and run  

Perfect for anyone using MiniMax H3 who wants better identity consistency across video generations.

### Who is this for?
- MiniMax H3 users who need reliable character references  
- ComfyUI creators working on consistent character videos  
- Anyone tired of manually creating or hunting for good reference sheets
